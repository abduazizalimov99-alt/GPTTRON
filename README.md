# GPTTRON — онлайн-тесты с проверкой Gemini AI

## Что внутри
- `app.py` — Flask-сервер и API, который использует Gemini API.
- `templates/index.html` — сайт GPTTRON.
- `questions.json` — вопросы и эталонные ответы; ключи не отправляются браузеру.
- `requirements.txt` — Python-зависимости.
- `render.yaml` — пример конфигурации развёртывания на Render.

## 1. Получи Gemini API-ключ
1. Открой [Google AI Studio](https://aistudio.google.com/).
2. Создай API key.
3. Не вставляй ключ в HTML или JavaScript и не публикуй его в GitHub. Используй переменную окружения `GEMINI_API_KEY`.

Google AI Studio / Gemini API доступен в Узбекистане по официальному списку регионов. Бесплатный тариф доступен для некоторых моделей, но лимиты могут меняться. На бесплатном тарифе содержимое запросов может использоваться Google для улучшения продуктов — не отправляй персональные данные учеников.

## 2. Запуск на компьютере (Windows)
1. Установи Python 3.10 или новее.
2. Открой папку проекта в терминале.
3. Создай виртуальное окружение и установи зависимости:

   ```powershell
   py -m venv .venv
   .\.venv\Scriptsctivate
   pip install -r requirements.txt
   ```

4. Скопируй `.env.example` в `.env` и вставь свой ключ в `GEMINI_API_KEY`.
5. Запусти сервер:

   ```powershell
   python app.py
   ```

6. Открой http://127.0.0.1:5000

Не отправляй `.env` другим людям и не добавляй его в GitHub.

## 3. Онлайн-размещение на Render
1. Создай приватный репозиторий GitHub и загрузи в него содержимое этой папки. Файл `.env` не загружай.
2. На [Render Dashboard](https://dashboard.render.com/) создай **New → Web Service** и подключи репозиторий.
3. Укажи:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
4. В разделе **Environment** добавь:
   - `GEMINI_API_KEY` — твой секретный API-ключ;
   - `GEMINI_MODEL` — `gemini-3.8-flash`;
   - `CHECKS_PER_MINUTE` — `30`.
5. Нажми Deploy. Render выдаст URL вида `https://имя-сервиса.onrender.com` — эту ссылку можно отправлять ученикам.

Если модель не доступна в AI Studio для твоего ключа, выбери модель с бесплатным тарифом, доступную в списке моделей AI Studio, и замени `GEMINI_MODEL` в настройках сервиса.

## Безопасность и лимиты
- API-ключ читается только сервером из переменной окружения.
- Эталонные ответы не выдаются через `/api/questions/...`; сервер проверяет ответы по своему `questions.json`.
- Вопросы с вариантами проверяются сервером без вызова ИИ.
- Открытые ответы ограничены 2000 символами; есть базовый лимит запросов на IP.
- Лимитер хранится в памяти одного процесса и сбрасывается при перезапуске. Для большой аудитории нужен общий rate limiter (например, Redis) и дополнительные ограничения.
- Бесплатный тариф имеет ограничения по запросам/скорости и может измениться. Для бесплатного тарифа Google указывает, что содержимое запросов может использоваться для улучшения продуктов. Не передавай в API персональные данные.

## Вопросы
Сейчас включено 118 вопросов: 28 по литературе и по 30 по биологии, химии и истории. Это не все 180 вопросов из более раннего списка. Чтобы добавить остальные, дополни `questions.json` в том же формате.


## Обработка временной перегрузки Gemini

Сервер повторяет запрос один раз после короткой паузы при временных ошибках (например, 503/429), затем пробует модель из `GEMINI_FALLBACK_MODEL` (по умолчанию `gemini-2.5-flash`). Если обе модели недоступны, ошибка остаётся видимой в Render Logs; ответ ученика сохраняется в интерфейсе, и тест можно завершить повторно.
